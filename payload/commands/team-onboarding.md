Create a short onboarding guide for a new contributor to this project $ARGUMENTS.

First explore the repository: read README/AGENTS.md/CONTRIBUTING.md, the build
and config files, and the top-level directory structure to learn the real setup,
test, and lint/format commands. Then write a guide covering: prerequisites,
setup steps, how to run/build/test, project layout, key conventions, and where
to look when stuck.

Use only commands and facts you can verify from the repo; mark anything you
couldn't confirm. Ask before writing the guide to a file — otherwise return it
in the response.
